# VSAgent Scientific Reference

## 1. 文档定位

本文件用于记录 VSAgent 分子筛选流程中的科学依据、方法适用条件、解释原则及案例。

本文件不定义 Agent 的执行权限，也不替代 `AGENTS.md` 中的确认机制。

具体工具调用和流程操作由 `docs/screening-playbook.md` 规定。

本文件的主要作用是：

- 为科学判断提供可追溯依据；
- 解释不同筛选方法的适用范围；
- 记录方法之间的关系与局限；
- 支持筛选结果的科学解释；
- 避免将计算预测误写为实验事实。

---

## 2. 分子筛选的证据层级

VSAgent 应区分不同类型的证据。

### 2.1 实验结构证据

实验结构可用于分析：

- 受体构象；
- 配体结合位置；
- 关键残基；
- 结合模式；
- 结构变化；
- 潜在相互作用。

实验结构是结构分析的重要依据，但仍需考虑：

- 结构分辨率；
- 缺失区域；
- 实验环境；
- 晶体或其他实验条件；
- 结构是否代表目标生物学状态。

实验结构不能自动证明所有候选分子均采用相同结合模式。

### 2.2 文献证据

文献可用于支持：

- 已知活性配体；
- 关键残基；
- 作用机制；
- 口袋定义；
- 突变影响；
- 实验活性；
- 结构–活性关系。

文献证据应关联原始来源。

当综述与原始实验报道存在差异时，应优先核查原始研究。

### 2.3 计算预测证据

计算预测包括：

- 分子相似性；
- 结构叠合；
- 口袋识别；
- 对接；
- DTA；
- QSAR；
- 药效团分析；
- 其他模型预测。

计算结果应明确标记为预测或计算证据，不得与实验数据混用。

### 2.4 实验证据

实验数据可用于验证：

- 分子是否具有活性；
- 结合是否发生；
- 预测结合模式是否合理；
- 关键残基是否参与结合；
- 计算筛选是否具有实际价值。

实验数据应保留实验条件和测量指标。

不同实验条件下获得的结果不一定能够直接比较。

## 3. 结构选择与口袋定义的科学依据

### 3.1 结构选择不是单一指标排序

受体结构的选择应综合考虑：

- 结构质量；
- 实验环境；
- 配体信息；
- 口袋状态；
- 研究目标；
- 结构完整性；
- 构象差异。

RMSD 可用于描述结构差异，但不能单独决定结构优劣。

结构质量较高的受体未必最适合当前筛选任务。

### 3.2 配体参考结构的价值

已知配体可以提供：

- 口袋定位线索；
- 结合模式参考；
- 关键残基信息；
- 配体构象约束；
- 结构筛选的初始依据。

但参考配体的结合模式不应被视为所有新分子的唯一可能模式。

### 3.3 口袋边界的解释

口袋定义涉及空间范围和残基集合。

5 Å 邻域可以作为初始分析范围，但不同体系中的相互作用范围、口袋边界和配体尺寸可能存在差异。

口袋边界应结合：

- 结构环境；
- 配体尺寸；
- 关键残基；
- 口袋几何；
- 具体分析目标。

固定距离阈值只能作为操作参数，不能替代科学判断。

### 3.4 脂质和去垢剂相关结构

脂质、去垢剂及其他非典型结构组分可能反映：

- 蛋白内部空腔；
- 膜蛋白相关区域；
- 疏水结合区域；
- 实验环境中的结构稳定因素；
- 非特异性结合。

判断其是否具有口袋参考意义时，应综合考虑：

- 分子结构；
- 所处空间位置；
- 周围残基；
- 结构重复性；
- 文献支持；
- 生物学环境。

单一分子尺寸或原子组成条件不能证明其为真实生物学配体。

## 4. 分子筛选方法的层级与适用条件

### 4.1 2D 相似性筛选

2D 相似性通常用于识别具有相似化学结构的分子。

Tanimoto 相似性可用于描述分子指纹之间的相似程度。

其优势包括：

- 计算成本较低；
- 易于解释；
- 适合已知活性化学型扩展；
- 便于快速筛选大型化学库。

其局限包括：

- 对三维构象信息表达有限；
- 相似分子不一定具有相似活性；
- 不相似分子也可能采用相似结合模式；
- 结果依赖指纹类型及分子表示方式。

因此，2D 相似性适合用作筛选入口，而不应单独作为活性结论。

### 4.2 形状相似性

形状相似性用于比较分子的三维空间形态。

适用于：

- 已知配体具有明确结合构象；
- 希望寻找形状相似的候选；
- 化学结构差异较大但可能具有相似空间特征的任务。

其局限包括：

- 依赖分子构象；
- 可能忽略关键化学相互作用；
- 构象不确定性会影响结果；
- 形状相似不意味着结合亲和力相似。

### 4.3 药效团筛选

药效团用于描述分子识别所需的关键空间和化学特征。

可包含：

- 氢键供体；
- 氢键受体；
- 疏水特征；
- 芳香环特征；
- 电荷特征；
- 空间约束。

药效团筛选适用于：

- 已有可靠结合模式；
- 已知关键相互作用；
- 希望在化学结构差异较大的分子中寻找共同特征。

其局限包括：

- 依赖参考结构或机制假设；
- 过强约束可能排除有效分子；
- 药效团模型不一定覆盖全部结合模式；
- 预测结果仍需后续结构或实验验证。

### 4.4 结构对接

结构对接用于探索候选分子在受体口袋中的潜在结合姿势。

其主要价值包括：

- 生成候选结合位姿；
- 分析潜在相互作用；
- 检查结构合理性；
- 支持候选分子排序；
- 为后续实验提供结构假设。

其局限包括：

- 受体构象可能不充分；
- 配体构象空间可能未充分采样；
- 溶剂和熵效应处理有限；
- 评分函数可能存在系统偏差；
- 对接结果依赖参数及结构准备。

Docking score 不能直接视为实验亲和力。

### 4.5 DTA 预测

DTA 模型用于预测蛋白–配体结合亲和力。

其价值包括：

- 对候选分子进行模型层面的排序；
- 辅助优先级判断；
- 与结构筛选形成互补；
- 支持实验候选选择。

其局限包括：

- 数据集分布偏差；
- 训练集与测试集相似性；
- 蛋白或配体分布外问题；
- 标签质量差异；
- 数据泄漏；
- 模型适用范围有限。

DTA 结果应结合模型性能和数据适用范围解释。

### 4.6 方法组合原则

筛选方法应根据证据和目标逐步升级。

建议路径：

2D 相似性
→ 形状相似性
→ 药效团筛选
→ 结构对接
→ DTA 或其他模型预测
→ 实验验证

上述路径不是固定流水线。

当已知结构和机制证据充分时，可以直接进入结构相关分析；当结构证据不足时，应避免过早依赖对接或复杂预测模型。

## 5. Docking score、亲和力与实验活性的区别

### 5.1 Docking score

Docking score 是特定对接程序及评分函数产生的计算指标。

它主要用于：

- 位姿排序；
- 候选结构过滤；
- 同一体系内的相对比较。

Docking score 不是实验测得的结合自由能，也不能直接转换为 IC50、Ki 或 Kd。

### 5.2 DTA 预测值

DTA 预测值是模型输出。

其可靠性取决于：

- 训练数据；
- 标签质量；
- 模型架构；
- 数据划分；
- 目标蛋白和配体与训练分布的相似性。

DTA 预测值应与模型评价指标一起解释。

### 5.3 实验活性

实验活性是通过实验测量得到的结果。

不同实验指标具有不同定义：

- IC50：达到半数抑制效果所需浓度；
- Ki：抑制剂解离常数；
- Kd：结合解离常数。

这些指标之间并不总能直接互换。

比较实验结果时，应考虑：

- 实验体系；
- 测量条件；
- 测量方法；
- 数据单位；
- 误差范围。

### 5.4 证据组合

Docking、DTA 和实验数据应作为互补证据。

当不同方法结果一致时，可以提高候选分子的优先级，但不能据此宣称已完成实验验证。

当结果不一致时，应检查：

- 受体结构；
- 口袋定义；
- 配体构象；
- 评分函数；
- 模型适用范围；
- 实验条件。

## 6. 结构–活性关系与共同特征

### 6.1 共同结构特征

多个候选分子具有共同子结构时，可以提出潜在的结构–活性关系假设。

但共同结构可能来自：

- 化学型本身；
- 数据集偏差；
- 分子筛选条件；
- 共同的非活性骨架；
- 真实的结合特征。

因此，共同子结构不应自动解释为活性决定因素。

### 6.2 结构–活性关系的验证

SAR 假设应尽可能通过以下证据支持：

- 实验活性数据；
- 结构对比；
- 关键残基分析；
- 分子修饰前后比较；
- 独立数据；
- 实验验证。

仅基于 docking score 或少量预测结果建立的 SAR 应明确标记为初步假设。

### 6.3 关键相互作用

关键相互作用应与结构位置对应。

对于氢键、盐桥、疏水作用、π–π 相互作用及其他相互作用，应核查：

- 相关原子；
- 相关残基；
- 几何关系；
- 结构环境；
- 计算方法。

相互作用分析可以帮助解释候选分子的结合模式，但不能单独证明结合亲和力或生物活性。

## 7. 筛选策略与科学解释

### 7.1 组内筛选

当已有活性化学型或参考配体时，可优先开展组内筛选。

适用于：

- 已知活性骨架；
- 结构类似物扩展；
- 局部化学空间探索；
- 已有 SAR 数据。

优点：

- 易于解释；
- 便于比较；
- 计算成本相对较低；
- 有利于建立结构–活性假设。

局限：

- 化学空间覆盖有限；
- 可能遗漏新型骨架；
- 依赖已有活性化学型的可靠性。

### 7.2 组外筛选

当现有化学型无法充分解释目标或覆盖不足时，可开展组外探索。

适用于：

- 新型结合模式探索；
- 已知配体空间不足；
- 机制驱动的化学空间扩展；
- 需要提高结构多样性。

组外筛选应注意：

- 结构多样性；
- 模型分布外风险；
- 预测不确定性；
- 口袋约束；
- 后续实验验证成本。

### 7.3 组内与组外的结合

组内与组外筛选可以形成互补策略。

组内筛选用于提高已有化学型的覆盖与精细化程度。

组外筛选用于探索新的化学空间和潜在结合模式。

二者的比例应由当前证据、研究目标和实验资源决定，而不是固定设置。

## 8. 结果解释与实验假设

### 8.1 候选分子优先级

候选分子优先级应综合考虑：

- 结构合理性；
- 对接结果；
- 亲和力预测；
- 化学结构特征；
- 已知实验数据；
- 模型不确定性；
- 可验证性；
- 实验可行性。

任何单一指标都不应决定最终候选名单。

### 8.2 实验假设

优先候选应形成明确的实验假设，例如：

- 某结构特征可能有助于口袋适配；
- 某关键残基可能参与配体识别；
- 某类分子修饰可能改变结合模式；
- 某候选可能采用不同的结合姿势。

假设应说明其依据和不确定性。

### 8.3 后续验证

后续验证可包括：

- 生化结合实验；
- 活性测定；
- 关键残基突变；
- 结构验证；
- 分子修饰比较；
- 其他适合研究目标的实验。

实验设计应围绕当前最关键的不确定性展开，而不是简单重复计算筛选。

## 9. 案例与经验记录

本章节用于持续记录已验证的方法经验。

新增案例时，应包含：

- 研究对象；
- 任务目标；
- 数据来源；
- 使用方法；
- 关键参数；
- 主要结果；
- 实验验证情况；
- 方法局限；
- 可迁移经验；
- 不适用条件。

案例结论不得直接推广至所有蛋白、配体或筛选任务。

每个案例应区分：

- 已验证事实；
- 计算结果；
- 经验总结；
- 尚未验证的假设。

## 10. 文献引用与维护规范

科学依据应尽可能引用原始文献。

建议记录：

- 作者；
- 年份；
- 题目；
- 期刊；
- DOI 或稳定链接；
- 对应支持的结论；
- 适用条件；
- 可能的局限。

新增方法、阈值或科学判断时，应明确其来源。

如果某项规则仅来自项目内部经验，应标记为内部经验，而不是普遍科学规律。

本文件应随着实验验证和新证据持续更新。
